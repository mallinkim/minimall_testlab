# AI 가 만든 테스트 리뷰 노트 (Mission 2)

대상: `ai_tests/*.test.js` (AI 도구가 생성했다고 가정). 기준: SRS · 계약서.
먼저 **측정**한다: `npm run coverage -- --tests ai_tests` 와 `npm run mutate:ai`. 그 다음 읽는다.

## 점검 체크리스트 (확인한 항목에 표시)
- [ ] 단언이 값을 비교하는가? (`assert.ok(x)` · 존재 여부 · 길이만 확인하지 않는가)
- [ ] 기대값이 독립적인가? (결과로 기대값을 계산하는 동어반복이 아닌가)
- [ ] 경계값이 있는가? (최소 · 최대 · 딱 맞는 값 · 바로 바깥)
- [ ] 오류를 제대로 확인하는가? (오류 코드까지 확인하는가, `try/catch` 로 삼키지 않는가, 오류가 안 나도 통과하지 않는가)
- [ ] 테스트 이름과 단언이 일치하는가?
- [ ] 테스트가 독립적인가? (한 테스트만 실행해도 통과하는가: `node scripts/test.js ai_tests --name "<테스트 이름>"`)
- [ ] 계약서의 실패 경로 · 동시성 · 권한 규칙이 빠져 있지 않은가?
- [ ] 같은 것을 반복하거나 구현 세부(저장소 내부 구조)에 묶여 있지 않은가?
