  - 4번(오류 확인): 14건 보고 — 오류 코드 미지정 9건, try/catch 로 오류를 삼켜 오류가 안 나도 통과하는 테스트 4건(결제 실패, PG 시간 초과, 취소된 주문 결제, 환불 실패), details(maxAddable, shortages) 미확인 2건. 기대 오류 코드를 계약서 오류 코드표와 대조해 모두 맞음을 확인. 에이전트가 놓친 부분: 오류가 났을 때 상태가 바뀌지 않아야 한다는 계약(결제 실패 시 주문 PENDING_PAYMENT 유지 · 결제 기록 FAILED, 취소된 주문 결제 시 PG 미호출, 이미 취소된 주문 취소 시 환불 · 재고 변화 없음, 재고 초과 시 장바구니 불변)을 사람이 추가로 찾아 ④ 고치기 대상에 포함
